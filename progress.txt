# Explore (trace) — Progress

## 2026-08-24 RECENTS NAME THEIR CHAIN

`RecentEntity` now carries the chain the entry was seen on, and the recents
rail and the ⌘K palette both build their links through one function,
`recentEntityView.hrefFor`. The palette used to call `scanPath` itself; it
does not any more, so the two surfaces cannot drift.

Which kinds get a chain is a rule, not an oversight. A transaction, a contract
and a block name theirs. An **address stays bare**, because `/address/0x…`
with no prefix is the documented "every chain" route and an address is valid
on all of them.

**The legacy decision.** An entry written before this change has no chain and
there is no way to recover one. It stays unset and links bare — exactly what
shipped before — so a resolve+redirect still finds the right chain on click.
A stored `chainId` that is not a positive integer (`null`, `"369"`, NaN) is
STRIPPED at load, because keeping one would build `/eip155/NaN/tx/0x…`. Both
paths are pinned by tests in `recentEntities.test.ts`.

The chain is deliberately NOT part of the entry's identity (`idOf`). One
address is one row whichever chain you reached it from; a revisit on another
chain overwrites the field, so the link follows the newest visit.

### SHIPPED

**The gas oracle stopped shipping its own memory to every browser**
(`2b19c21`). `GET /api/gas/oracle` returned **647,932 bytes** on chain 369, of
which 1,158 were real. `ring` was 98.4% of it — twenty blocks, each holding
every transaction's tip. The home page polls it every five seconds, so one
open tab pulled ~7.4 MB a minute to render four numbers. The route did
`serialize(state)` on a PRODUCER state object; the package says four times
over that these fields are producer-local and publishers should strip them.
Now 1,259 bytes. **515x.**

**The explorer home page, rebuilt** (`963bbf1`, `3e30dd2`, `c42a515`, plus
three merged branches). An outage used to be invisible, both lists now have
real empty and error states, the page names its chain, and both lists sit on
`EntityRow`. Details in the commits.

**A transaction is no longer named after a mined 4byte collision** (`0f13199`)
and **Settings measures whether an endpoint serves history** (`3faa100`).

### HARD-WON — DO NOT RE-DERIVE

- **A "state" object from a package is not a wire format.** Check for a
  `toPublishable` before serializing one wholesale. Ours lived in the relay
  and was never called; nobody noticed for as long as the endpoint existed,
  because no client read the extra fields — they were just sent.
- **`truncate` is `white-space: nowrap` + `overflow: hidden`.** A `break-all`
  flex child inside it cannot wrap, collapses to nothing, and SPILLS its text
  across whatever is beside it. This produced two separate bugs in one hour: a
  method name overlapping the fee readout, and a 66-char hash running 196px
  past the content pane. One line holds one thing.
- **A grid item defaults to `min-width: auto`** and refuses to shrink below
  its content, so `break-all` on a child never fires. `min-w-0` on the item is
  what lets it act.
- **`viewport.spec.ts` was blind for its whole life.** It asserted only
  `document.documentElement.scrollWidth <= 375`, and `app-content` is a
  `flex-1 overflow-auto min-w-0` containment boundary that absorbs overflow
  internally — the document never moves off 375. Four of nineteen routes were
  overflowing while it passed: `/ui` 223px, `/network-health` 205px,
  `/explorer` 202px, `/` 37px. It asserts the pane now. `/` and
  `/network-health` are still marked `test.fail()` — genuinely broken.
- **`test.fail()` goes red when a test PASSES.** That is the feature: fixing
  EntityRow and the gas strip fixed `/ui` as a side effect, and the gate said
  so without anyone thinking to check.
- **`--color-text-muted` was 3.77:1** on the card background against a 4.5:1
  floor, used 450 times. Now `#808996`, the darkest value on the same hue line
  that clears AA on every surface.
- **Two formatters named `formatGwei` disagreed in public.** Chain 1's stat
  tile said "0.11 gwei" beside a gas strip saying "base 0 gwei". One shared
  `formatGweiDisplay` now.
- **Parallel agents each start their own dev server.** Mine landed on 11802
  while an agent's worktree held 11801, and I screenshotted THEIR build and
  briefly believed my changes had not applied. Read the port out of the log
  every time.
- **`npx playwright test` collides with the repo's own install** ("did not
  expect test() to be called here"). Use `node_modules/.bin/playwright`.
- **`npm run test:unit --workspace=packages/api` needs the API on :10100.**
  Five `/api/tx/:hash` tests live under `tests/unit/` and hit the live server;
  without it they fail with a bare `createConnectionError`.
- **`npm run test` is NOT the tests.** It runs the API *integration* suite.
  Four suites: web vitest, api unit, api integration, Playwright.
- **jsdom does no layout.** Geometry belongs in e2e, always.
- **op hangs on a STALE `~/.config/op/op-daemon.sock`.** `op --version` works
  while `op whoami` hangs. Fix: `pkill -f "op daemon"; rm -f` the socket.
- **Two implementer subagents must not share a working tree.** Worktree
  isolation worked cleanly here — three branches, three merges, one conflict
  auto-resolved.

### OPEN

- **`/` overflows 37px and `/network-health` 205px at 375px.** Both marked
  `test.fail()` in `viewport.spec.ts` with their measurements.
- **Spinner-forever in `AddressView`.** The backend does NOT hang — chifra
  bounds at 30s, viem at 30s. The defect is a 15–30s load with no feedback and
  no client-side defence. Needs per-call-site `AbortSignal.timeout` at **35–40s**
  (above the observed latency, NOT the 8–10s used for cheap lookups),
  `Promise.allSettled`, per-section degradation.
- **The rail's swap branch — the two audits contradict each other.** 25 blocks
  said 33 multicall-wrapped vs 7 direct ("under 1%"); 85 blocks over 716
  successful txs said the OPPOSITE, 23 direct vs 7 wrapped, with the current
  regex already matching ~3.2%. Re-measure before trusting either. Separately
  ~90% of decoded successful txs have no `functionName` at all, so a swap-only
  rail is permanently a minority feature — a generic rail may be right, and
  that is a product call.
- **The home page shows no fee per transaction any more.** Deliberate: it did
  not survive a two-line row. If this audience wants it back, the mempool view
  is the place, not a scan list.
- **4byte guesses still render as facts** when a selector has several
  candidates. Needs a candidate count carried to the UI.
- **Sepolia is missing from `valve-tech/chainlist`.** Our other entries ARE
  upstream already (DefiLlama PR #2938, merged July); the `rpc-collector`
  dataset is stale because it was vendored five days before that merge. Our
  chainlist checkout is 143 commits behind. Needs the user.
- **`recentEntityView.ts` and `AppShell/buildResults.ts` build chain-less
  paths** — `RecentEntity` has no `chainId` field.
