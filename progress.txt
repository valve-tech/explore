### HARD-WON — DO NOT RE-DERIVE

- **There is no archive filter anywhere, and there never was.** chainlist
  records a provider's logging claim and nothing about pruning, so
  `rpc-collector`'s `collectRpcs` has no archive option and `RpcEndpoint` has
  no archive field — at ANY version. `probeEndpoints` measures liveness only,
  which a pruned node passes. I twice reported `checkArchive`/`requireArchive`
  as existing in 0.24.0. They do not. Ask the node or you do not know.
- **Measure the state you are shipping, not the one before it.** I measured
  the endpoint chip row at 375px, found it clean, and shipped. The overflow
  only appears AFTER the probe adds a verdict to every label —
  "eth-sepolia-testnet.api.pocket.network · recent blocks only" is 425px
  against a 365px pane. The e2e caught it; my manual pass could not, because I
  never pressed the button first.
- **`0x00000000` is not a selector.** It is a raw fallback blob's first four
  bytes. 4byte holds 49 MINED names for it. Any list that takes `matches[0]`
  prints one of them as fact.
- **The signature cache had no ORDER BY.** Same selector, different name on
  different days, with nothing in the code to point at. Fixed, but the general
  problem stands: 4byte is a dictionary of guesses and both list views present
  the first guess as a fact.
- **`npm run test:unit --workspace=packages/api` needs the API on :10100.**
  Five `/api/tx/:hash` tests live under `tests/unit/` and hit the live server.
  Without it they fail with a bare `createConnectionError` that reads like a
  Postgres problem. Start `npm run dev:api` first; then 684/684 pass.
- **`npm run test` is NOT the tests.** It runs the API *integration* suite.
  There are FOUR: web vitest, api unit (`test:unit`), api integration, and the
  Playwright gate (`npm run test:e2e --workspace=packages/web`, needs
  `npx playwright install chromium` once).
- **jsdom does no layout.** `getBoundingClientRect` returns zeros, so no
  vitest test can see a chip escaping its pane. Geometry belongs in e2e.
- **The sidebar is a selector minefield**, and so is `{name: "Test"}` —
  substring matching also selects chips named
  "eth-sepolia-**test**net.api.pocket.network". Use `exact: true`.
- **A finite 0 is not "no data".** `EntityRow` withholds its fill only for a
  NON-finite share.
- **Terminal-return views get no breadcrumb.** `MultiChainAddressView` and
  `BlockHeightView` return before `ExplorerPanel` renders one.
- **`op` hangs on a STALE `~/.config/op/op-daemon.sock`.** `op --version`
  works while `op whoami` hangs; that is the tell. Fix:
  `pkill -f "op daemon"; rm -f ~/.config/op/op-daemon.sock`.
- **Two implementer subagents must not share a working tree.** Disjoint FILES
  do not make a shared git INDEX safe. Read-only audits in parallel are fine.

### OPEN

- **Spinner-forever in `AddressView`.** Framing corrected: the backend does
  NOT hang — `chifra/appearances.ts` bounds at 30s and viem carries its own
  30s. The real defect is a 15–30s load with no feedback and no client-side
  defence at all. Fix is per-call-site `AbortSignal.timeout` at **35–40s**
  (above the observed natural latency, NOT the 8–10s used for cheap lookups),
  `Promise.allSettled`, and per-section degradation.
- **The rail's swap branch — the two audits contradict each other.** A 25-block
  scan found 33 multicall-wrapped swaps vs 7 direct-named ("well under 1%").
  An 85-block scan over 716 successful txs found the OPPOSITE: 23 direct vs 7
  wrapped, with the current regex already matching ~3.2%. Do NOT quote the
  <1% figure. Re-measure before relying on either. Separately, ~90% of decoded
  successful txs have no `functionName` at all, so a swap-only rail is
  permanently a minority feature — a generic rail may be the right answer, and
  that is a product call.
- **4byte guesses still render as facts** when a selector has several
  candidates. Would need a candidate count carried to the UI.
- **The explorer home page needs a facelift.** Raised in passing; not scoped.
- **Sepolia is missing from `valve-tech/chainlist`.** Correction: our other
  entries are ALREADY upstream (DefiLlama PR #2938, merged July). The

  five days before that merge. Our chainlist checkout is 143 commits behind.
  Needs the user: a DefiLlama PR, the stale-branch call, and an npm publish.
